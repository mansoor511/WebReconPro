## 📌 About

**WebRecon Pro** is a powerful and comprehensive web reconnaissance tool designed for ethical hackers, penetration testers, and security researchers. It automates the entire reconnaissance phase of a web application security assessment.

> ⚠️ **Disclaimer:** This tool is for **educational and ethical testing only**. Use it only on websites you own or have **written permission** to test.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🔍 **IP Resolution** | Resolves domain to IP addresses |
| 🌐 **DNS Enumeration** | A, AAAA, MX, NS, TXT, SOA, CNAME records |
| 🔎 **Subdomain Discovery** | 68+ common subdomains |
| 📁 **Directory Brute-Force** | 97+ common directories |
| 🕷️ **URL Crawling** | Crawls and extracts all URLs |
| 📜 **JavaScript Analysis** | Finds API endpoints in JS files |
| 🔌 **Port Scanning** | 40+ common ports |
| ⚙️ **Technology Detection** | Detects server, CMS, frameworks |
| 📋 **WHOIS Lookup** | Domain registration info |
| 🔒 **SSL Check** | Certificate issuer and expiry |
